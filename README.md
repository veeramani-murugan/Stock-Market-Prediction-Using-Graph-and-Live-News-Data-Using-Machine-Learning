# Stock Market Prediction

A machine learning-based web application that predicts stock market trends using historical market data and live news sentiment.

## Features

- Stock Prediction
- Sentiment Analysis
- Graph Visualization
- Flask Web Application

## Technologies Used

- Python
- Flask
- TensorFlow
- NLTK
- SQLite

## Project Description

- Developed a machine learning model to predict stock market trends.
- Integrated live news data for sentiment analysis.
- Used graphical data to visualize stock market trends.
- Implemented a Flask-based web application.
- Used SQLite for data storage and management.

## How It Works

1. Collects stock market data.
2. Processes and analyzes the data.
3. Collects relevant financial news.
4. Performs sentiment analysis on the news.
5. Combines market and sentiment data.
6. Predicts the stock market trend.
7. Displays the results through graphs and the web interface.

## How to Run

### 1. Install Dependencies

```bash
pip install -r requirements.txt
```

### 2. Run the Application

```bash
python app.py
```

### 3. Open in Browser

After running the application, open the URL displayed in the terminal.
